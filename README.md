# Currículo Online

## Sobre o Projeto

Este projeto consiste em uma página de currículo desenvolvida utilizando HTML e CSS, com o objetivo de apresentar informações profissionais, acadêmicas e habilidades de forma organizada e responsiva.

O currículo foi publicado utilizando o GitHub Pages, permitindo o acesso online através do navegador.

## Tecnologias Utilizadas

- HTML5

- CSS3

- Git e GitHub

- GitHub Pages

## Objetivo

O objetivo deste projeto é praticar os conceitos fundamentais de desenvolvimento web, como:

- Estruturação de páginas com HTML;

- Estilização utilizando CSS;

- Organização de informações profissionais;

- Publicação de sites estáticos com GitHub Pages.

## Informações Apresentadas

O currículo contém:

- Dados pessoais;

- Contato;

- Formação acadêmica;

- Cursos complementares;

- Habilidades técnicas;

- Objetivos profissionais.
