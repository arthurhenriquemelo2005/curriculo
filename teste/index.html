Estratégia de implantação: Do Chão de Fábrica à Nuvem Corporativa

Ambiente OT (Borda)

Coletores Leves (Edge)

Gateways industriais rodam imagens otimizadas para hardware restrito, coletando dados de CLPs via Modbus/OPC UA.

Dockerfile

Orquestração e Sincronia

O Compose liga o Broker MQTT local. O coletor só envia dados se o Broker estiver 100% funcional.

depends_on: broker + healthcheck

Tolerância a Quedas

Em caso de falha de internet, os dados são salvos no disco da máquina industrial (Store-and-Forward).

volumes: local_storage

Docker Registry

Distribuição Segura
Atualizações (OTA)

Ambiente IT (Servidor)

A Stack Completa

O servidor central consolida o Banco de Dados, a API e o Dashboard Gráfico com apenas um comando atômico.

$ docker compose up -d

Isolamento de Segurança

O banco de dados não tem acesso público. Apenas a interface de visualização é mapeada para os usuários.

networks: rede_isolada

Auto-Cura do Sistema

Se o servidor reiniciar, todos os contêineres e serviços voltam sozinhos, lendo os dados salvos nos cofres.

restart: always
